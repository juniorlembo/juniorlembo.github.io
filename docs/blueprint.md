# **App Name**: Citadel Guard

## Core Features:

- Section Navigation: Enable smooth, animated scrolling between sections for improved user experience.
- Technical Arsenal Display: Showcase technical skills and tools using clear, categorized labels.
- Project Showcase: Display recent projects in a visually appealing carousel format.
- Article Display: List latest articles with titles, brief descriptions, and links to read more.
- Contact Form: Allow users to submit their information and messages through a form.

## Style Guidelines:

- Primary color: Sombre (#1B211A), reminiscent of digital networks and information.
- Background color: Very dark gray (#212121) for contrast and to emphasize content.
- Accent color: Orange (#e34d04) for highlights and interactive elements.
- Headline font: 'Space Grotesk', a sans-serif with a modern, tech-forward feel.
- Body font: 'Inter', a sans-serif for readability and a neutral appearance.
- Use clean, minimalist icons related to cyber security and technology themes.
- Section to section, to emulate the reference design.
